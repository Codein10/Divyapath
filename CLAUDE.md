## Project rules

Detailed rules live in `.claude/rules/` and load automatically:

- `folder-structure.md`: where every kind of file goes (feature-based structure)
- `architecture.md`: layers, import direction, how features connect
- `code-style.md`: naming, TypeScript, components
- `state-and-data.md`: TanStack Query, Zustand, API client, errors, config and secrets
- `styling-and-ui.md`: theme tokens, layout, accessibility
- `testing-and-quality.md`: tests, commands and the definition of done

Stack: Expo SDK 58 + Expo Router, TypeScript (strict), TanStack Query, Zustand, Zod, expo-secure-store, Jest + React Native Testing Library, ESLint + Prettier.
